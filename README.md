# 随机点名

上课点名用的小网页：**先准备一份待点名名单，然后从名单里随机抽若干个名字**。
纯前端、无需安装、无需联网，双击 `index.html` 就能用（推荐 Chrome / Edge）。

所有数据（名单、本轮已抽状态、抽取记录）都只存在**访问者自己的浏览器**里（localStorage，键 `roll-call/v1`），
不会上传到服务器，别人打开看到的仍然是一份空名单。

---

## 快速开始

1. 双击打开 [index.html](index.html)。
2. 把名单加进去：手动输入姓名回车、把一批名字粘贴进文本框，或者点「导入名单文件」读一份花名册。
3. 设置抽取人数，点「开始抽取」。

如果需要通过 http 访问（某些浏览器对本地文件的限制较严），可以在项目目录下执行：

```bash
node tools/serve.js              # 本机 http://localhost:5173（打开就是点名页）
node tools/serve.js --local      # 只允许本机访问
```

`serve.js` 默认监听 `0.0.0.0`，所以启动后会打印局域网地址（如 `http://192.168.1.5:5173`），
同一 Wi-Fi / 同一校园网下的手机、平板等设备可以直接打开这个地址。
Windows 首次运行会弹出防火墙询问，勾选「专用网络」并允许即可。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 手动添加名单 | 单个添加：输入姓名回车；批量添加：把名字粘贴进文本框，每行一个，也支持逗号、顿号、空格分隔（可以直接从 Excel 里复制一列粘进来），填好后选「追加到名单」或「替换整个名单」 |
| 导入花名册文件 | 支持 `.xlsx` / `.xls` / `.xlsm` / `.csv` / `.txt`。自动判断「姓名」在哪一列（表头写 `姓名`、`名字`、`学生`、`Name` 等都认得；找不到表头时按「哪一列最像人名」来猜），也可以手动换列，或者选「整张表」把多列名单（例如分组名单）一次全取出来；导入前会预览解析出的名字，并提示跳过/去重了多少项 |
| 随机抽取 | 抽取人数可以直接填，也有 1 / 2 / 3 / 5 / 剩余全部 的快捷按钮；一次抽取里不会抽到同一个人；开着「本轮不重复」时，抽过的人不再参与，直到点「重置本轮」 |
| 结果 | 被点到的名字按抽取顺序显示成大卡片，可以一键复制；抽取时名字会滚动一下（不想要滚动可以在选项里关掉） |
| 抽取记录 | 每次抽取都会记一条（时间、抽到的名字、当时候选人数），可以复制某一条，也可以导出成 txt |
| 名单管理 | 名单以名字标签显示：点名字可以切换「本轮已抽」标记（有人请假时用得上），点名字右边的 × 删除；「更多」里可以导出名单、重置本轮、清空记录、清空整个名单 |

几个实现上的说明：

- 随机数优先用 `crypto.getRandomValues`（浏览器自带），并用拒绝采样去掉取模偏差，保证每个人被抽到的概率一样；不支持时才退回 `Math.random`。
- 导入花名册时会自动跳过学号、序号、性别、表头、合计行等明显不是姓名的内容，学号写在姓名同一格（如 `2026001 张三`）也能认出来；名字前面的序号（`1.` `1、` `1 `）会被去掉。
- 名单、本轮已抽状态、抽取记录都存在浏览器本地，和任何其它页面的数据互不影响，也不会上传服务器。

## 目录结构

```
index.html                 页面结构（顶栏、名单区、抽取区）
styles.css                 全部样式，含深色模式和响应式布局
js/sheet.js                读上传的 Excel / CSV 文件 → 二维数组
js/roster.js               名单的数据模型、姓名解析、随机抽取（不依赖界面）
js/rollcall.js             界面渲染与交互
vendor/xlsx.full.min.js    SheetJS（本地内置，离线可用）
samples/                   示例花名册（xlsx 两张表 / csv 一份）
tools/gen-samples.js       重新生成 samples/ 里的示例花名册
tools/test-roster.js       名单与随机抽取的无浏览器测试
tools/serve.js             可选的本地预览服务器（默认对外开放，便于局域网访问）
```

## 开发与测试

```bash
node tools/gen-samples.js    # 重新生成示例花名册
node tools/test-roster.js    # 点名测试（姓名识别、花名册取列、随机抽取、记录与本地保存）
node tools/serve.js          # 本地预览 http://localhost:5173
```

打开 <http://localhost:5173>，用 `samples/示例-花名册.xlsx` 或 `samples/示例-花名册.csv` 试导入最方便。

## 发布到 GitHub Pages（可选）

这个项目是纯静态的，整份目录直接发布即可。新建一个仓库并推上去：

```bash
git add -A
git commit -m "说明这次改了什么"
git remote add origin <你的仓库地址>
git push -u origin main
```

然后在仓库的 Settings → Pages 里把 Source 设为 `Deploy from a branch` / `main` / `/`。
发布后根地址（`https://<用户名>.github.io/<仓库名>/`）就直接打开点名页：首页文件已经叫 `index.html`，
`tools/serve.js` 访问 `/` 时也是读它，本地预览和线上地址一致。
（本仓库已发布在 <https://a3342151701-pixel.github.io/rollcall/>。）

## 已知限制

- 数据只存在当前浏览器的本地存储里，不联网、不跨设备同步；换设备请用「更多 → 导出名单」。
- 名单按姓名去重，所以**同名的两个人只能算一个**（导入花名册时会提示去掉了几个重名）；班里有同名学生时，可以在名字后面自己加个标记（如 `张三（1 班）`）。
- 不含「按学号顺序」「按小组轮换」这类规则，每次都是从当前候选池里等概率随机抽。
